## 公开演示数据验证

`examples/sample-questions.json` 中的 8 道题独立编写，覆盖单选、多选、填空与判断。`scripts/New-SampleBank.ps1` 将其生成为程序可读取的 DOCX。

发布前会针对实际发布包执行 `--self-test`，检查格式化答案、选项倒序、短数字选项、题型约束、OCR 与取消操作；本轮汇总见 `public-validation.json`。真实使用效果仍取决于所选题面和本机 Windows OCR 组件。
