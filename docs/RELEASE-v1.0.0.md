# v1.0.0 · Windows 离线截图搜题

下载 `offline-question-search-v1.0.0-win-x64.zip`，完整解压后运行 `离线搜题.exe`。

- 点击“截图搜题”，每次手动框选一道题的题干和完整选项。
- 点击“结束检测”，取消当前识别并关闭答案。
- 选择题显示选项字母与答案内容，多选题逐项显示；支持填空和判断。
- 使用 Windows 本地中文 OCR 与 DOCX 题库索引；运行时不调用网络服务，不后台轮询截图。
- 包含题型约束、选项顺序匹配、缺失标记恢复与一次增强重试。

运行要求：Windows 10/11 64 位、.NET Framework 4.8、Windows 简体中文 OCR 组件。

本包仅附独立编写的 8 道演示题，不包含原始用户题库、日志、真实截图或原始测试报告。使用自己的 DOCX 题库时，将其放在程序同级目录；建议先移走演示题库后再重启程序。

本轮对实际发布包的演示数据自检通过：8 道原文回查、4 道选择题倒序、7 张生成题面图 OCR，以及题型、短数字选项和取消检查。测试范围见仓库 `docs/VALIDATION.md`，不代表任意实际截图的准确率保证。

`SHA256SUMS.txt` 提供 ZIP 文件的 SHA-256 校验值。仓库同时提供源码、构建和打包脚本。
